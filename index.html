The problem

Early interior and site layout work is usually split across a floor-plan sketch, a separate spreadsheet for code compliance and cost, and a rendering tool for client presentation — three disconnected artifacts that drift out of sync the moment the layout changes.

What ZKR Atelier does

A single scene is the source of truth. Placing, moving or resizing an object immediately re-runs the same clearance/egress analysis that feeds the Accessibility card, the 3D compliance overlay, the inspector and the exported PDF — so those four views can never disagree with each other.

Capabilities

What's actually in the workspace

Each of these maps to a working feature in the app — not a roadmap item.

01

3D scene

Three.js-driven real-time viewport with 3D perspective, city-overview and floor-plan camera modes.

02

Spatial & compliance analysis

A single analysis pass checks fire egress, clearance and accessibility, driving the overlay, inspector and report together.

03

Measurement tool

Press M, click a start point, and read a live running distance as you move — measurements persist with the project.

04

Contextual inspector

One panel that adapts to what's selected — an object's properties, or a flagged clearance issue and its fix.

05

Command palette

Ctrl/⌘+K surfaces only the actions that are actually runnable in the current mode and selection.

06

Cost & capacity

Furniture subtotal, built value and seating capacity update live as the plan changes.

07

Presentation mode

A distraction-free walkthrough view for showing a layout to a client, with a single-key exit.

08

PDF export

Generates a client-ready report of the current layout and its analysis, built with jsPDF.

09

Scenario templates

Start from a set of commercial, hospitality and public-space templates instead of a blank plot.

Workflow

How a session actually runs

  1. 01

    Pick a template

    Start from a scenario template or a blank plot, and set the plot dimensions.

  2. 02

    Place & arrange

    Add furniture and objects from the catalog directly into the 3D scene.

  3. 03

    Check & measure

    Read live compliance status, measure distances, and resolve flagged clearance issues.

  4. 04

    Present & export

    Switch to presentation mode for a walkthrough, then export a PDF report of the result.

Under the hood

Technical highlights

  • ENGINEThree.js real-time 3D viewport with three interchangeable camera modes.
  • LOGICA single, pure spatial-analysis function feeds every compliance surface in the app.
  • UIA contextual inspector and a scoped command palette, both driven by current selection/mode.
  • EXPORTClient-side PDF report generation via jsPDF — no server round-trip.
  • I18NString keys throughout the interface for straightforward localization.
  • DEPLOYA fully static build — no backend required to run the workspace.
